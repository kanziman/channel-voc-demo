# channel-voc-demo

Live dispatch target for the **Channel VOC Intelligence Dept.** plugin (AX hackathon).

Every Issue and Pull Request in this repository was created **automatically** by the
plugin's Triage/QA and Growth-Ops arms, from analysis of real public customer-support
conversations (Bitext dataset, anonymized). Nothing here is hand-written.

- Issues → engineering bug tickets synthesized from high-₩ conversation clusters.
- PRs → FAQ / help-center diffs proposed from recurring questions.

See the department dashboard for the analysis these artifacts trace back to.
