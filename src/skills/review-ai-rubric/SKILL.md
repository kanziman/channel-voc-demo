# AI 심사위원 역공학 평가 스킬 (AI Reviewer Rubric)

## 개요
본 스킬은 AX 해커톤의 AI 심사위원이 평가하는 정적/동적 검증 항목을 역공학하여 제출물 전체의 신뢰도와 정합성을 100점 만점으로 자동 측정합니다.

## 평가 루브릭 (100점 만점)

### 1. 제출 규격 및 파싱 유효성 (20점)
- `src/.codex-plugin/plugin.json` 유효한 JSON 형식 및 필수 키 존재 (10점)
- `src/skills/<NAME>/SKILL.md` YAML Frontmatter (`name`, `description`) 파싱 유효성 (5점)
- `logs/` 및 `README.md` 필수 위치 존재 여부 (5점)

### 2. 3자 정합성 (Log-Skill-QA Consistency) (30점)
- `logs/` 대화 원본에 실제 개발/테스트 수행 기록 존재 여부 (10점)
- `SKILL.md` 프롬프트 내용과 5개 서면 답변의 작동 설명 모순 존재 여부 (10점)
- 로그 사후 편집/삭제/가공 흔적 및 환각(Hallucination) 여부 (10점)

### 3. 공개 데이터 출처 검증 가능성 (Verifiable Grounding) (25점)
- 서면 답변 및 README에 제시된 통계/수치/주장의 출처 명시 여부 (10점)
- 출처가 웹 검색 및 공개 자료로 실제 확인 가능한 데이터인가? (15점)

### 4. Codex 스킬 & MCP 기술 실행성 (25점)
- Codex CLI / Claude Code 환경에서 가동 가능한 명확한 프롬프트 지침 구조 (15점)
- MCP 서버 또는 외부 연동 인터페이스 명세의 완전성 (10점)

## 실행 방법
프로젝트 루트에서 이 스킬을 실행하여 **AI 채점표 및 감점 요인 / 즉시 수정 가이드**를 출력하세요.
