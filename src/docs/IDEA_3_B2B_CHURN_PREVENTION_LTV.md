# [Idea 3 종합 보고서] B2B 고객 이탈 위험 사전 감지 및 LTV 극대화 Codex 에이전트

## 1. 리서치 배경 & 객관적 근거 (Research & Evidence)

### 1.1 공개 시장 데이터 및 현황
- **B2B SaaS 이탈의 치명성**: B2B SaaS 기업에서 고객 이탈률(Churn Rate)이 5% 줄어들면 기업 이익은 **25%~95% 증가**함 (Bain & Company 리서치).
- **이탈 사전 징후**: B2B 고객의 이탈은 갑자기 일어나지 않으며, 대화 톤의 냉담화, 기능 문의 빈도 감소, 특정 키워드(환불, 계약 해지, 가격 비교 등) 언급 등의 사전 징후를 보임.
- **기존 방식의 한계**:
  - 영업/CSM(고객성공매니저)이 수백 개 B2B 계정을 일일이 모니터링할 수 없어 이탈 직전에야 상황을 파악하고 대처에 실패함.

### 1.2 채널톡 리서치 & 대표 인터뷰 연계성
- **채널톡 리서치 연계**: 채널톡은 국내외 **100,000개 이상의 기업**이 사용하는 B2B Customer Success 플랫폼임.
- **채널톡 인터뷰 내용 연계 (00:00–00:44)**:
  > *"비즈니스가 존재하는 한 고객 커뮤니케이션의 중요성은 계속될 것이며, 기업과 고객 간 커뮤니케이션 문제를 해결하는 것이 본질"*
- **시사점**: B2B 고객 커뮤니케이션 데이터를 기반으로 계정의 건강도(Account Health)를 실시간 추적하여 LTV(고객 생애 가치)를 극대화.

---

## 2. 문제 정의 (Problem Statement)

> **"B2B 고객의 이탈 징후는 채널톡 대화 속에서 이미 수개월 전부터 나타나지만, 담당자가 이를 감지하지 못해 고가치 계정(Key Account)을 상실한다."**

1. **시그널 감지 부재**: 고객의 뉘앙스 변화(불만 누적, 대체재 탐색 등)를 사람이 감지하기 어려움.
2. **사전 대응(Proactive Action) 부재**: 이탈 시그널이 나와도 CSM에게 자동 브리핑되거나 리텐션 전략이 제공되지 않음.
3. **CRM 데이터 파편화**: 채널톡 커뮤니케이션 내용과 Salesforce/HubSpot CRM 데이터 간 실시간 동기화 부재.

---

## 3. 솔루션 아키텍처 & 스코프 (3~4주 공수 엔터프라이즈 설계)

본 솔루션은 **B2B 대화 감정/위험도 분석 ➔ Churn Score 산출 ➔ CSM 자율 브리핑 & 리텐션 키트 생성 ➔ CRM 동기화**를 담당합니다.

### 🛠️ 4대 핵심 모듈 및 3~4주 공수 명세
1. **Module 1: B2B Churn Risk Scoring Engine**
   - 대화 내 부정 감정, 계약 관련 키워드, 사용법 관련 포기 징후를 분석해 0~100점의 Churn Score 실시간 산출.
2. **Module 2: Proactive Executive Briefing Agent**
   - Churn Score 70점 이상 발생 시 담당 CSM/영업책임자에게 "고객사 이슈 요약 및 대면 미팅 가이드" 작성.
3. **Module 3: Personalized Retention Kit Agent**
   - 고객의 주요 불만 사항을 해결해 줄 신기능 가이드, 1:1 온보딩 세션 신청서, 맞춤 할인 제안서 자동 생성.
4. **Module 4: B2B CRM Sync Connector (MCP)**
   - Salesforce, HubSpot 등 B2B CRM에 채널톡 대화 기반의 Account Health 및 딜 위험 상태 실시간 업데이트.

## 4. 검증 방안 (Verification Plan)

1. **정량적 검증 (Churn Prediction Accuracy)**:
   - 과거 B2B 고객 이탈/지속 대화 데이터셋 300건을 바탕으로 Churn Score의 이탈 예측 정확도 (Target: Precision 85% 이상) 검증.
2. **정성적 검증 (Retention Kit Utility)**:
   - 생성된 리텐션 가이드 문서가 실제 B2B CSM 영업 현장에서 고객 설득에 활용 가능한 수준인지 검증.

## 5. 해커톤 5개 질문 사전 답변 준비

1. **무엇을, 누가, 어떤 상황에서 쓰나요?**: B2B SaaS 기업의 CSM(고객성공매니저)과 영업팀이 채널톡 대화로 B2B 고객의 이탈 위험을 감지하고 리텐션 전략을 실행할 때 사용.
2. **왜 이 문제를 선택했나요?**: B2B 사업의 핵심인 LTV(고객 생애 가치) 방어와 Churn 방지가 기업의 생존을 결정짓기 때문.
3. **플러그인은 어떻게 작동하나요?**: 채널톡 B2B 대화 수집 -> Codex Churn Engine 스코어링 -> CSM 브리핑 생성 -> CRM MCP 동기화.
4. **AI를 어떻게 활용했나요?**: 대화 맥락 속 이탈 징후 NLP 분석, 맞춤형 B2B 제안서 자동 작성, CRM 동기화 워크플로우에 LLM 활용.
5. **어떻게 검증했나요?**: 300건의 B2B 대화 시나리오 데이터셋으로 Churn 감지 정확도 및 리텐션 제안서 유용성 검증.

## 6. 보완: 실현성 · 차별화 · 리스크 (Review Addendum)

### 6.1 ⚠️ 데이터 출처 정직성 (검토 필요)

- Bain "이탈 5% 감소 → 이익 25~95% 증가"는 실제로는 **리텐션(고객유지) 통계**(Reichheld/Bain, 1990)로, churn 문맥으로의 재해석이며 오래되어 반론 여지가 큼. 인용 시 "리텐션 5%p 향상 시" 원문 뉘앙스로 정확히 쓰고 출처·연도 명기.
- "100,000개 기업"은 채널톡 공개 수치 범위 내에서 최신 공식 발표 값으로 확인 후 사용.

### 6.2 실현성 평가: 3개 후보 중 데모 난이도 최상 (정직한 인정)

- 이탈은 **수개월에 걸친 시계열 시그널**이라 해커톤 기간·단발 데모로 "예측 정확도"를 실증하기 가장 어려움. Module 4(CRM 양방향 동기화)는 외부 계정·권한 의존으로 4주 실현성 낮음.
- 제출 후보로 택한다면, 평가 축을 "예측"이 아니라 **"주어진 대화 묶음에 대한 위험 신호 설명 품질 + CSM 브리핑 유용성"** 으로 이동해 실증 가능 범위로 좁힐 것.

### 6.3 해커톤 데모 MVP vs 엔터프라이즈 비전 (스코프 분리)

| 구분 | 범위 | 데모 방식 |
| :--- | :--- | :--- |
| **MVP (실제 구현·시연)** | 한 계정의 최근 대화 묶음 → ①위험 신호 근거 추출(냉담 톤/해지·가격 키워드/문의 감소) ②Churn Score + 근거 ③CSM 브리핑 문서 생성 | Codex Skill + 샘플 계정 로그 |
| **확장 (로드맵)** | Module 4 Salesforce/HubSpot 쓰기 동기화, 실시간 사용량 텔레메트리 | 아키텍처로 제시 (읽기 전용 연동부터 단계화) |

> Churn Score는 블랙박스 숫자로 두지 말고 **근거 문장(evidence) 동반 출력**을 필수화 — "70점"보다 "이 3개 발화 때문에 70점"이 CSM에게 실사용됨.

### 6.4 채널톡 실제 연동 표면 (Integration Surface)

- **입력**: 채널톡 Open API `userChats`/`messages`, 계정(그룹) 단위 대화 이력 조회.
- **출력**: 브리핑은 Slack/문서 MCP로. CRM은 **읽기·제안 우선**, 쓰기 동기화는 후속 단계로 명확히 분리(권한·데이터 정합성 리스크).

### 6.5 기존 채널톡 AI 및 CSM 도구와의 차별화

일반 대시보드는 "사용량 지표"로 헬스를 봄. 본 솔루션의 차별점은 **대화 언어(감정·의도) 기반 조기 신호** — 사용량이 아직 정상인데 톤이 먼저 식는 계정을 잡아내는 것. 이 "언어 선행 지표" 각도를 전면에.

### 6.6 개선된 검증안 (순환논리 제거)

- 자기생성 300건 지양. **과거 실제 계정의 유지/이탈 결과(라벨)** 를 alignment로 쓰는 후향 검증이 이상적. 불가 시 CSM 전문가가 라벨링한 held-out 세트 사용.
- 지표: 단일 Precision 85% 대신 **PR 커브 + 조기 감지 리드타임(이탈 며칠 전 경보?)** 보고 — B2B에선 "얼마나 일찍"이 정확도만큼 중요.
- 브리핑 유용성: 현직 CSM 블라인드 평가(그대로 고객미팅에 쓸 수 있는가 1~5점).

### 6.7 리스크

- **오탐(false positive)로 멀쩡한 계정에 과잉 리텐션 개입** → 상위 위험 계정만 사람 검토 후 액션.
- 대화 감정 분석 편향(업종·문체 차이) → 근거 문장 노출로 CSM이 판단 보정 가능하게.
- B2B 대화·계약 데이터 민감성 → 데모는 익명화 샘플만.
